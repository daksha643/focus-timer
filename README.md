# ⏱️ Focus Timer

A Pomodoro-style focus timer. No installation needed — just open `index.html` in any browser.

## Features
- Focus / Short Break / Long Break modes
- Custom timer durations via Settings ⚙️
- Task tracker with pomodoro count
- Session history
- Everything saves automatically in your browser

## How to run
1. Download or clone this repo
2. Double-click `index.html`
3. Done!

## Upload to GitHub Pages (free hosting)
1. Push this folder to GitHub
2. Go to repo Settings → Pages → Deploy from main branch
3. Your timer is live at `https://YOUR_USERNAME.github.io/focus-timer`
